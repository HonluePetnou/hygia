# Hygia — Conventions

- TypeScript strict, fonctions/composants courts, un rôle par fichier.
- Aucune dépendance ajoutée sans la mentionner dans le résumé de session.
- Branches : `feat/…`, `fix/…`. Jamais de push direct sur `main`/`master`.
- Commits clairs ; merge sur `main` toujours manuel.
- Lint + typecheck + tests avant de considérer une tâche « faite ».
